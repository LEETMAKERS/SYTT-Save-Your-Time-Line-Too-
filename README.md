# Save Your Time Line Too:

A game where two players who represent alternate timelines of a character play a pong like game and the winner is the one with the biggest score.
The ball is considered to be the character oscillating between the two timelines, the winner is the timeline where the character gets a good fate,
and vice versa.

# Game mechanics:

- Each player has 4 buttons, the two on the side are for changing the direction of the ball before sending it.
- The two buttons on the centre are for launching/deflecting the button, if the appropriate button depends on which half of the screen the ball is in
- If the player presses the left button while the ball is on the right side he loses by 1 point
- If a player scores he gets to launch the ball again
- The deflect is detected when the ball is close enough

# Used material :
- 2x MAX72 8x32 led matrix module
- ESP32
- 8 push buttons
- Jumper wires
